# NOX

NOX is an Enterprise-grade NVR/VMS system. The free version supports up to 4 channels.

## Requirements

* Ubuntu 24.04 (amd64) or Raspberry Pi 4B/5 (arm64, Debian 13 Trixie)
* RAM 8GiB or higher

## Installation

```bash
curl -fsSL [https://github.com/yiyolcorp/nox-release/releases/latest/download/install.sh](https://github.com/yiyolcorp/nox-release/releases/latest/download/install.sh) | sudo bash
