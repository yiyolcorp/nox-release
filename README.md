# NOX

NOX는 Enterprise 급 NVR/VMS 시스템입니다. 무료 버전은 최대 4채널을 지원합니다.

## 요구사항
- Ubuntu 24.04 (amd64) 혹은 Raspberry Pi 4.0 이상 (arm64)

## 설치

```bash
curl -fsSL https://github.com/yiyolcorp/nox-release/releases/latest/download/install.sh \
  | sudo bash
```
## 제한사항
- 무료 버전은 최대 4채널의 라이브와 녹화, 녹화 데이터는 최대 7일까지만 보관 가능합니다. 분석은 제공되지 않습니다.
- https://nox.yiyol.com 에서 더 많은 자료를 찾을 수 있습니다.
